# Looker Studio build guide: Wispr Flow India dashboard (10 pages)

Per-page versions of these steps are in `docs/looker/` (index: `docs/looker/README.md`). They are generated from this guide (`python -m src.deck.looker_docs`); edit this file, not them.

**What this is.** The dashboard is built by hand in Looker Studio from the generated tables in `outputs/dashboard/` (eleven CSVs and one workbook, `wispr_dashboard_data.xlsx`, with one worksheet per CSV). Nothing in this repository creates, publishes or shares a Looker Studio report; every step marked **Manual** is performed in a Google account by whoever builds it. Report links, Google Sheets and sharing settings are not part of the repository.

**Design choices (why the data is shaped this way).**
- **No calculated fields and no chart filters.** Every derived value (labels, percentages, readable names, month labels, headline cells) is computed in the data files, so the report has fewer failure points.
- **Percentages are delivered as numbers in percent units** (`share_pct` 21.5 means 21.5%), so no Percent type changes are needed.
- **One purpose per page**, short readable column names and a fixed palette.
- **Cross-filtering is switched off.** Clicking a bar in Looker Studio applies that value as a filter to other charts on the page (the **Reset** button clears it); with it on, a stray click can leave one category showing everywhere. Part 2.5 explains how to turn it off.

**Data status shown on every review page:** *interim sample, 321 of 600 selected reviews tagged (newest Google Play reviews only, no App Store); not all users; not India-specific; not causal.* The banner is data-driven (a column in the data), so it updates by itself when the data is regenerated.

## Updating an existing report after the data changes

When the generated tables change, rebuild the workbook (`make dashboard`) and update only the sources whose data changed; check `git diff outputs/dashboard` to see which CSVs differ.
1. **Manual.** Upload the new `wispr_dashboard_data.xlsx` to Drive and open it as a new private Google Sheet (keep the previous Sheet until the update is verified).
2. **Manual.** For each changed source: **Resource > Manage added data sources > Edit** > **Edit connection** > choose the new Sheet and the same-named tab > **Reconnect**, review the field changes Looker lists, and **Apply**. Per Google's documentation, new fields are added, fields no longer in the data are removed, renamed fields are treated as a removal plus an addition, and field type and aggregation edits are kept for fields that still exist. Charts that used a removed or renamed field show a configuration error and must be re-pointed in **Setup**.
3. Check that field types survived (Part 1 step 7) and that row counts match the table in Part 1.
4. Sources whose CSV did not change need no action.

## Part 2. Report-wide setup (Manual, 15 minutes)

### 2.1 Editor map
Menu bar **File Edit View Insert Page Arrange Resource Help**; toolbar **Add data, Add a chart, Add a control, T text box, Image, Line, Shapes, Theme and layout, Reset, View**; canvas in the centre; **Properties panel** on the right with **Setup** and **Style**; page list on the left. If the Properties panel is hidden, click an element, then the small arrow tab at the far right.

### 2.2 Operations you will repeat
1. **Add a page:** **Page > New page**. Rename or duplicate: right-click the page in the page list.
2. **Text box:** toolbar **T**, drag a box, type. Format with the floating bar (font, size, bold, colour); fill and border in **Style**.
3. **Chart:** toolbar **Add a chart**, pick a type, drag a rectangle. Pick the data source in **Setup > Data source**.
4. **Add a field to a chart:** **Setup** > **Dimension** / **Metric** boxes. Click a metric pill to change its **aggregation**; choose **Max** (rows are already final values; Sum would add repeated values). To rename a field in this chart only: click the pill and edit **Display name** (or the pencil).
5. **Select several elements:** Shift+click, or drag a rectangle on empty canvas. **Group:** right-click > **Group**. **Align/distribute:** **Arrange > Align / Distribute**.
6. **Position and size:** drag to move, drag handles to resize. **If your editor shows Position/Size fields** (some versions, under **Style** near the bottom) type the numbers in this manual. **If you don't,** place by eye: the canvas is 1280 px wide, so 10% is 128 px, and align neighbours with step 5. Turn on **View > Show grid / Snap to grid** if offered.
7. **Copy/paste:** select, Ctrl/Cmd+C then Ctrl/Cmd+V; the copy lands on top, drag it. Use this for footers and repeated tables.
8. **Preview:** **View** (toolbar) shows the report as a viewer; **Edit** returns.

### 2.3 Canvas, theme, navigation
**Theme and layout** (toolbar) > **Layout**: **Canvas size > Custom**: width **1280**, height **800**, same for all pages. **Header** off. **Navigation** **Top** (page tabs). **Theme**: a plain light theme with a white background.

### 2.4 Pages and palette
Create ten pages (names are the tab names): `1 Summary`, `2 Gap scenarios`, `3 Review themes`, `4 Review detail`, `5 Review months`, `6 Competitors`, `7 Prices`, `8 Offers and checkout`, `9 Experiments`, `10 Experiment grid (appendix)`.

Enter a colour: click any swatch > **Custom** > type the hex > Enter.

**Type scale (all pages):** title 22 bold; subtitle 12 (`#555555`); chart/table text 11; notes 12; footer 10.

## Part 15. Troubleshooting

| Symptom | Fix |
|---|---|
| One category (for example `free_tier_limits`) shows everywhere | Cross-filter from clicking a bar. **Reset**, then untick **Apply filter** on each chart (2.5). |
| Numbers doubled or too large | Aggregation is Sum. Click the metric pill and choose **Max**. |
| A field you need is missing in the pill list | The chart uses the wrong data source; change **Setup > Data source**. Fields come only from that source. |
| Percent shows `0.215` | You are using an old field. Use `*_pct` fields (already in percent units). |
| Month labels look like `month=2026-10` or are in reverse order | Old data. Re-import the new workbook (Part 1) and use `month_label`; sort ascending. |
| `unknown` became blank | Re-import from the original xlsx; keep the five criterion columns, `score`, `usd_list_price`, `inr_per_month` as Text. |
| Table headers truncated | Edit **Display name** of the field, widen the column, enable **Wrap text**, reduce font to 10. |
| Chart empty | Check the source and that the fields exist; open the source in **Resource** and **Refresh fields**. |
| "Data set configuration error" in View | Credentials are not Owner's, or the Sheet was moved or deleted. Reconnect. |
| Text cut off in a text box | Enlarge the box or reduce the font; boxes do not auto-grow. |
| Data changed in the Sheet but not in the report | In View mode use the refresh icon; or **Resource > Manage added data sources > Edit > Refresh fields**. |
| Line chart shows a zero for July | Style: **Missing data** must be **line breaks**. July is meant to be blank. |

## Part 16. Unresolved items and limits of this manual

- **Interface variation.** Menu names, especially **Chart interactions**, **Position/Size**, **Conditional formatting on text** and **Missing data**, can differ by Looker Studio version. Each place has a fallback. The guide was written from Google's documentation and could not be run against the live product, so the manual is a best description, not a recording.
- **Interim sample.** 321 of 600 reviews are tagged; the tagging job is paused by an apparent daily quota. When it finishes: regenerate (`python -m src.analysis.run_a1`, then `python -m src.deck.dashboard_csv`), re-import the workbook into the same Sheet, **Refresh fields**, and the banner changes automatically.
- **Unverified evidence on pages 6 to 8.** Wispr-specific UPI on Google Play, the unnamed third payment option, offer redeemability today, the first Hinglish release date.
- **Implied FX.** 94.1 INR per USD comes from TechCrunch's rounded conversion; there is no independent FX rate.
- **Competitor evidence.** Scores come from Google Play listings (install bands are global, not India), developer claims and vendor pages. Apple dictation and Google AI Edge Eloquent are unscored; Superwhisper has no Play listing found. Hinglish and price claims are advertised, not tested.
