## Build steps
Purpose: the headline in ten seconds. Elements: title, subtitle, one chart, three scorecards, one takeaway box.

1. Title: `India is 14% of installs but 2% of in-app revenue (reported)`.
2. Subtitle: `Reported by Sensor Tower via TechCrunch, Oct 2025 to Apr 2026; in-app purchases only. The indices are scenarios, not causal estimates.`
3. **Column chart** `(24, 100, 580, 430)`: **Add a chart > Bar chart** (vertical columns; if the list shows "Column chart", choose it). Setup: source `summary`; dimension `measure`; metric `share_pct` > **Max**; display name `India share of total (%)`. Style: **Single colour** `#3B6EA8`; **Show data labels** on; **Left Y axis** min `0`, max `16`; gridlines light grey; legend off. Untick **Apply filter** (00-start-here, section 2.5).
   ✅ Two columns: `Installs from India` 14 and `In-app purchase revenue from India` 2.
4. **Three scorecards** `(630, 100, 620, 120)`, `(630, 240, 620, 120)`, `(630, 380, 620, 120)`. For each: **Add a chart > Scorecard**, source `summary`, metric > **Max**, then rename the metric (Display name) so the label under the number explains it, and set **Style > Decimal precision 3** (if there is no such option, accept the default). Number colour `#222222`, background white, border light grey.

   | Card | Metric | Display name | ✅ Value |
   |---|---|---|---|
   | 1 | `rev_per_install_index` | `Revenue per install vs the global rate (scenario)` | 0.143 |
   | 2 | `price_index` | `Price index: India 3.4 vs 12 USD annual list price` | 0.283 |
   | 3 | `residual_index` | `Residual: conversion, mix, measurement, other (identity, not causal)` | 0.504 |
5. **Takeaway box** `(24, 550, 1232, 170)`: a rectangle (**Shapes > Rectangle**, fill `#F5F5F5`, border `#8A8A8A`) with a text box on top, size 13: `India's revenue per install is 0.143 of the global rate. The price gap alone would imply 0.283. The remaining 0.504 mixes conversion, mix, measurement and other factors and cannot be apportioned from public data; across scenarios it ranges from 0.223 to 1.224 (page 2). Public proxies only. This is an arithmetic identity, not an attribution.` Group the rectangle and text.

**STOP AND VERIFY:** **View**. Columns 14 and 2 from a zero axis; cards 0.143 / 0.283 / 0.504; no red tiles; nothing overlapping; footer visible.
Troubleshooting: *a card shows 0.286, 0.566 or 1.008* = aggregation is Sum on a two-row source (each index is repeated on both rows); set the metric to Max. *Columns show other numbers* = wrong field (use `share_pct`).

## Troubleshooting (this page and general)
| Symptom | Fix |
|---|---|
| Only one category shows after you clicked a bar | Cross-filtering. Press **Reset** (toolbar), then untick **Apply filter** on every chart (00-start-here, 2.5). |
| Numbers are doubled or too large | Aggregation is Sum. Click the metric pill and choose **Max**. |
| A field is missing in the field list | The chart uses the wrong data source. Change **Setup > Data source**. |
| Chart is empty or shows a red error tile | Check the source name, that every field exists (Resource > Manage added data sources > Refresh fields), and that credentials are Owner's. |
| Text or headers are cut off | Enlarge the element, turn on **Wrap text**, reduce the font to 10. |
| A value you expected is blank | Blank means suppressed or unknown on purpose; never replace it with 0 (set **Missing data** to line breaks, not zero). |
