# 00 Start here: data, editor basics and report setup

Do this once, before any page guide. Generated from `docs/looker_studio_setup.md`.

## Updating an existing report after the data changes

When the generated tables change, rebuild the workbook (`make dashboard`) and update only the sources whose data changed; check `git diff outputs/dashboard` to see which CSVs differ.
1. **Manual.** Upload the new `wispr_dashboard_data.xlsx` to Drive and open it as a new private Google Sheet (keep the previous Sheet until the update is verified).
2. **Manual.** For each changed source: **Resource > Manage added data sources > Edit** > **Edit connection** > choose the new Sheet and the same-named tab > **Reconnect**, review the field changes Looker lists, and **Apply**. Per Google's documentation, new fields are added, fields no longer in the data are removed, renamed fields are treated as a removal plus an addition, and field type and aggregation edits are kept for fields that still exist. Charts that used a removed or renamed field show a configuration error and must be re-pointed in **Setup**.
3. Check that field types survived (Part 1 step 7) and that row counts match the table in Part 1.
4. Sources whose CSV did not change need no action.

## Part 1. Load the data (about 20 minutes, Manual)

The workbook holds **eleven** tables, shaped for the pages. When replacing an older set of sources, do a clean swap instead of editing them in place.

1. **Get the new file.** In the repo: `outputs/dashboard/wispr_dashboard_data.xlsx` (regenerated by `python -m src.deck.dashboard_csv`; the matching CSVs sit beside it). Do not edit it in Excel and save it back.
2. **Import to a new Google Sheet.** In Google Drive: **New > File upload** the xlsx, then double-click it and choose **Open with Google Sheets**, then **File > Save as Google Sheets**. Rename the sheet `wispr_dashboard_data`. Keep the 11 tab names. Keep it **private**.
3. **Check the tabs** (open each). Expected rows (not counting the header) and columns:

| Tab (data source name) | Rows | Columns | Used on page |
|---|---|---|---|
| `summary` | 2 | 9 | 1, 2 |
| `decomposition` | 12 | 6 | 2 |
| `reviews_themes` | 17 | 18 | 3, 4 |
| `reviews_monthly` | 4 | 7 | 5 |
| `competitors_matrix` | 10 | 8 | 6 |
| `competitors_evidence` | 34 | 6 | 6 |
| `pricing_chart` | 8 | 6 | 7 |
| `pricing` | 14 | 9 | 7 |
| `offers` | 7 | 11 | 8 |
| `experiments_headline` | 3 | 13 | 9 |
| `experiments_grid` | 252 | 10 | 10 |

   **STOP AND VERIFY 1:** in the Sheet, `competitors_matrix` shows the word `unknown` in many cells and the digits 0 to 3; `pricing` column `inr_per_month` shows `unknown` for three rows; `reviews_monthly` row `2026-07` has **empty** percentage cells. If Sheets changed any of these (for example turned `unknown` into blanks), re-import from the original file before continuing.
4. **Clean slate (only when replacing an older version).** In edit mode, on every page click the canvas, **Ctrl/Cmd+A**, **Delete**. Then **Resource > Manage added data sources** and **remove** (trash icon) the old sources. Calculated fields live inside those sources and go with them.
5. **Add the eleven data sources.** For each tab: **Add data** (toolbar) > connector **Google Sheets** > pick `wispr_dashboard_data` and the tab > tick **Use first row as headers** > **Add** > **Add to report**. (Looker prompts "You are about to add data to this report"; confirm.) One tab = one data source.
6. **Rename** each source to the tab name: **Resource > Manage added data sources > Edit (pencil)**, click the name top-left, type, **Done**. Also set **Data credentials > Owner's credentials** on each (so public viewers do not need access to the Sheet).
7. **Check field types** (Edit > field list). Text columns must be Text, numbers Number. The only columns that must stay **Text** although they contain digits: all five criterion columns in `competitors_matrix` (`android_in_india`, `hinglish_support`, `reach_global_play`, `price_relevance`, `feature_overlap`), `score` in `competitors_evidence`, and `usd_list_price`, `inr_per_month` in `pricing`. If Looker made any of them Number, click the type and choose **Text**.

**STOP AND VERIFY 2:** eleven sources with the names above, Owner's credentials, and the text columns as Text.

## Part 2. Report-wide setup (Manual, 15 minutes)

### 2.1 Editor map
Menu bar **File Edit View Insert Page Arrange Resource Help**; toolbar **Add data, Add a chart, Add a control, T text box, Image, Line, Shapes, Theme and layout, Reset, View**; canvas in the centre; **Properties panel** on the right with **Setup** and **Style**; page list on the left. If the Properties panel is hidden, click an element, then the small arrow tab at the far right.

### 2.2 Operations you will repeat
1. **Add a page:** **Page > New page**. Rename or duplicate: right-click the page in the page list.
2. **Text box:** toolbar **T**, drag a box, type. Format with the floating bar (font, size, bold, colour); fill and border in **Style**.
3. **Chart:** toolbar **Add a chart**, pick a type, drag a rectangle. Pick the data source in **Setup > Data source**.
4. **Add a field to a chart:** **Setup** > **Dimension** / **Metric** boxes. Click a metric pill to change its **aggregation**; choose **Max** (rows are already final values; Sum would add repeated values). To rename a field in this chart only: click the pill and edit **Display name** (or the pencil).
5. **Select several elements:** Shift+click, or drag a rectangle on empty canvas. **Group:** right-click > **Group**. **Align/distribute:** **Arrange > Align / Distribute**.
6. **Position and size:** drag to move, drag handles to resize. **If your editor shows Position/Size fields** (some versions, under **Style** near the bottom) type the numbers in this manual. **If you don't,** place by eye: the canvas is 1280 px wide, so 10% is 128 px, and align neighbours with step 5. Turn on **View > Show grid / Snap to grid** if offered.
7. **Copy/paste:** select, Ctrl/Cmd+C then Ctrl/Cmd+V; the copy lands on top, drag it. Use this for footers and repeated tables.
8. **Preview:** **View** (toolbar) shows the report as a viewer; **Edit** returns.

### 2.3 Canvas, theme, navigation
**Theme and layout** (toolbar) > **Layout**: **Canvas size > Custom**: width **1280**, height **800**, same for all pages. **Header** off. **Navigation** **Top** (page tabs). **Theme**: a plain light theme with a white background.

### 2.4 Pages and palette
Create ten pages (names are the tab names): `1 Summary`, `2 Gap scenarios`, `3 Review themes`, `4 Review detail`, `5 Review months`, `6 Competitors`, `7 Prices`, `8 Offers and checkout`, `9 Experiments`, `10 Experiment grid (appendix)`.

| Use | Hex |
|---|---|
| Main series | `#3B6EA8` (blue) |
| Second series | `#E07B39` (orange) |
| Third series / neutral / unknown | `#8A8A8A` (grey) |
| Text | `#222222` |
| Interim banner text | `#B00020` (dark red) |
| Table header fill | `#3B6EA8`, white text |

Enter a colour: click any swatch > **Custom** > type the hex > Enter.

**Type scale (all pages):** title 22 bold; subtitle 12 (`#555555`); chart/table text 11; notes 12; footer 10.

### 2.5 Turn off cross-filtering
For **every chart and table** on every page (do it right after creating each element): select it, open **Setup**, scroll to **Chart interactions** (or **Interactions**), and **untick Apply filter** (cross-filtering). If you don't see that section in your version, look under **Style** for **Interactions**. If a chart ever shows a single category after you clicked it in View mode: click **Reset** (toolbar in Edit; top of the report in View) and fix this setting.

### 2.6 Standard page furniture (every page)
- **Title** text box `(24, 16, 1232, 44)`, size 22 bold.
- **Subtitle** text box `(24, 62, 1232, 26)`, size 12, `#555555`.
- **Footer** text box `(24, 764, 1232, 24)`, size 10: `Data as of 2026-10-18. Public proxies only, no internal Wispr data. Review themes are an interim sample. Scenarios are not forecasts or causal estimates.` Create once on page 1, copy-paste to the other nine pages (same position).
- Content area: `y = 100` to `y = 750`, left/right margins 24 px, gap between elements 20 px.
- **Interim banner** (pages 3, 4, 5 only): described in each page; it is a data-driven table, not typed text.
