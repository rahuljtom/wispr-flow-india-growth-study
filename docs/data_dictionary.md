# Data dictionary

## Null and special-value semantics
| Value | Meaning | Never |
|---|---|---|
| empty cell in a numeric column | Suppressed (fewer than 30 reviews) or not available; shown as blank, with a text status where one exists | treated as 0 |
| `unknown` | No sourced evidence for a score or price | scored as 0 |
| `0` (competitor score) | A real score (for example reach below 100k global installs) | used for missing evidence |
| `suppressed (n<30)` | Label that replaces a share when the group has fewer than 30 reviews | |
| `not applicable` | The field does not apply (for example a free product has no list price) | |
| `not stated` | The source gives no value | |
| `0` (share) | A real zero: the theme occurs in none of the reviews of a group that is large enough to show | confused with suppression |

Percentages in dashboard tables are in **percent units** (`share_pct` 21.5 means 21.5%). In `data/processed` tables, `share`, `ci_lo`, `ci_hi` and `missed_share` are fractions (0.215 means 21.5%).

## Numbers ledger: `data/ledger/numbers_ledger.csv`
| Column | Meaning |
|---|---|
| claim_id | Stable ID (R-001 ...) |
| used_in | Slide, appendix or chart where the number appears |
| label, value, unit | Plain-language description, the value (numbers or short text such as an interval) and its unit |
| status | reported / derived / assumption / estimated / unknown (see `docs/methodology.md`) |
| source_url, source_title, source_date, retrieved_on | Provenance; a URL is required for `reported` |
| derivation | Formula and input claim IDs (derived/estimated) |
| n, date_range | Sample size and period where relevant |
| caveat | Limitation shown in footnotes when material |
| human_reviewed | yes/no: whether a person has checked the row |

## Dashboard tables: `outputs/dashboard/dashboard_<name>.csv` and `wispr_dashboard_data.xlsx`
One worksheet per table, named without the `dashboard_` prefix. Aggregates only: no review text, reviewer names or review identifiers. Generated by `src/deck/dashboard_csv.py`.

**summary** (2 rows): `measure` (installs, or in-app purchase revenue, from India), `share_pct` (reported share of total, %), `rev_per_install_index`, `price_index`, `residual_index` (ratios), `residual_min`, `residual_max` (range across the sensitivity grid), `window`, `source`.

**decomposition** (12 rows): `scenario` (text), `missed_revenue_pct` (share of India revenue assumed missed by the source), `window_at_india_price_pct` (share of the window at India pricing), `rev_per_install`, `price_index`, `residual` (ratios, 3 decimals).

**reviews_themes** (17 rows, one per theme): `rank`, `theme_label`; for all tagged reviews `n_with_theme_all`, `share_all_pct`, `ci_lo_all_pct`, `ci_hi_all_pct` (Wilson 95%), `share_all_label` (text with interval), `mean_rating_all`; for one- and two-star reviews `n_with_theme_low`, `share_low_pct`, `ci_lo_low_pct`, `ci_hi_low_pct`, `share_low_label`; denominators `reviews_all`, `reviews_low_rated`, `reviews_selected`; `coverage_note` (interim status), `tagger_note`.

**reviews_monthly** (4 rows): `month_label` (YYYY-MM), `reviews` (tagged reviews that month), `status` (`shown` or `suppressed (n<30)`), `praise_productivity_pct`, `accuracy_general_pct`, `pricing_paywall_pct` (blank when suppressed), `coverage_note`.

**competitors_matrix** (10 rows): `competitor`; scores as text `0`-`3` or `unknown` in `android_in_india`, `hinglish_support`, `reach_global_play`, `price_relevance`, `feature_overlap`; `criteria_known` (count of the five that are sourced), `known_score_total` (sum of known scores, maximum 15).

**competitors_evidence** (34 rows): `competitor`, `criterion`, `score`, `rationale`, `source_url`, `retrieved_on`; only criteria with a sourced score.

**pricing_chart** (8 rows): `label`, `inr_per_month` (INR per user per month), `product`, `billing` (`annual` means billed annually, `monthly` billed monthly), `source_url`, `group`. Only prices with a stated billing period.

**pricing** (14 rows): `product`, `plan`, `billing`, `usd_list_price` (text), `inr_per_month` (text: a number, `unknown`, `free (...)` or a Play item range with the note `billing period not stated`), `free_tier`, `source_url`, `retrieved_on`, `fx_note`.

**offers** (7 rows): `offer`, `what_is_offered`, `duration`, `eligibility`, `restrictions`, `platform`, `android_specific`, `redeemable_today` (`UNVERIFIED` where not established), `evidence` (primary/secondary), `status`, `source_url`.

**experiments_headline** (3 rows): `experiment`, `primary_metric`, `baseline_pct`, `mde_points` (absolute percentage points), `n_per_arm`, `enrolment_days_default`, `follow_up_days`, `total_days_default` (default scenario: Android 50%, eligible 80%, exposed 100%; E3 platform-agnostic), `total_days_min`, `total_days_max` (across scenarios), `guardrails`, `decision_rule`, `caveat`.

**experiments_grid** (252 rows): `experiment`, `baseline_pct`, `mde_points`, `android_share_pct`, `eligible_share_pct`, `exposed_share_pct`, `n_per_arm`, `enrolment_days`, `follow_up_days`, `total_days`.

## Processed and interim tables
| File | Content |
|---|---|
| `data/processed/decomposition_scenarios.csv` | `missed_share`, `price_window_share`, `rev_per_install_index`, `price_index`, `residual_index` (fractions and ratios) |
| `data/processed/themes_by_segment.csv`, `themes_monthly.csv` | `segment`, `theme`, `n_segment`, `n_with_theme`, `share`, `ci_lo`, `ci_hi`, `mean_rating`, `suppressed` (True when the segment has fewer than 30 reviews; then share and interval are blank) |
| `data/processed/sentiment_overall.csv` | Sentiment counts and shares of the tagged sample |
| `data/processed/a1_coverage.json` | Tagged count, selected sample size, completeness flag, store mix and date range of the tagged sample |
| `data/processed/competitor_matrix.csv` | Long form: `competitor`, `criterion`, `score`, `source_url`, `retrieved_on`, `rationale` |
| `data/processed/competitor_ranking.csv` | `total`, `known`, `unknown`, `min_possible`, `max_possible` per competitor |
| `data/processed/competitor_sensitivity.csv` | Leader and runner-up when each criterion is dropped |
| `data/interim/competitor_play_stats.csv` | Google Play listing facts per candidate (global install band, rating, ratings count, release and update dates, in-app item range in INR with no billing period, description keyword flags, listing URL) |
| `data/processed/competitor_pricing.csv`, `value_ladder.csv` | Vendor-stated prices, billing periods, INR equivalents at `fx_inr_per_usd` and the FX basis |
| `data/processed/offers.csv` | Offers with eligibility, restrictions, evidence type and status |
| `data/processed/pricing_snapshots.csv` | Wayback snapshots of the Wispr pricing page (USD tokens found, free-limit snippet, whether an INR price appears) |
| `data/processed/experiment_sizing.csv` | Full sizing grid with guardrails, follow-up days, total days, unit note and decision rule |
| `data/processed/trends_event_study.csv`, `trends_summary.json` | Index of own pre-period mean for usable states; usability diagnostics and the not-estimable status |
| `data/interim/trends_<query>.csv` | Weekly Google Trends interest: `date`, `geo`, `target`, `anchor` (zero and missing kept distinct) |
| `data/interim/eval_*.json`, `frozen_config*.json`, `tagging_runs/*.json` | Tagger evaluation results (aggregate metrics and gold IDs only), frozen configurations, run records (config and counts, no text) |
| `data/interim/bulk_sample_counts.json` | Seed and counts of the bulk review sample by store, rating and language |
| `data/logs/pull_log.csv`, `failure_log.csv` | Every pull (source, endpoint, parameters, time, rows, SHA-256, status) and every failed attempt with retry number |

## Not distributed (private or restricted)
`data/raw/` (raw pulls and archived pages), `data/private/` (gold set, labels, un-scrubbed review table), `data/processed/wispr_reviews.csv` (scrubbed review text), per-review tags and the tagging cache, and the hashed review-ID list of the bulk sample. The review table schema is documented in `src/transform/reviews.py` (`PUB_COLS`).
